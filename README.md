# EscrowX

## AI-Powered Web3 Escrow Platform

EscrowX is an AI-powered Web3 escrow platform designed to make digital transactions safer, smarter, and more transparent.

## Features

- 🔐 Secure escrow transactions
- 🤖 AI-powered risk analysis
- 💰 Web3 and blockchain integration
- 📊 Transaction monitoring
- ⚡ Simple and user-friendly interface

## Technology

- HTML
- CSS
- JavaScript
- React
- Web3

- Advanced AI fraud detection
- Wallet integration
